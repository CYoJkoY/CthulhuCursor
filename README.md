## 📖 Introduction

Cthulhu Cursor is a Windows cursor theme pack inspired by the cosmic horror works of H.P. Lovecraft. Each pointer incorporates Cthulhu Mythos elements — tentacles, eldritch eyes, ancient runes — plunging your desktop into an unspeakable atmosphere.

### Highlights

- 🎨 **Full Coverage** — All 17 standard Windows pointer states, no exceptions
- 🎬 **Animated** — The "Busy" and "Working in Background" pointers feature smooth animations
- 🖱️ **Plug & Play** — Standard `.cur` / `.ani` formats, no extra software required
- 🎯 **High Legibility** — Dark cosmic style balanced with everyday usability

## 📥 Installation

### Requirements

- **OS**: Windows 10 / Windows 11 (Windows 7/8 also supported)
- **Disk Space**: < 5 MB
- **Extra Software**: None

### Method 1: Manual Installation (Recommended)

1. **Download** this repository and extract it to a permanent location (do not delete the folder — cursor files must remain in place).

   ```bash
   git clone https://github.com/your-username/cthulhu-cursor.git
   ```

2. **Open Mouse Settings**
   - `Win + I` → Bluetooth & devices → Mouse → Additional mouse settings
   - Or search "Mouse Settings" directly

3. **Switch to the "Pointers" tab**

4. **Replace each pointer**
   - Select each pointer state in the list
   - Click "Browse"
   - Choose the corresponding `.cur` or `.ani` file

5. **Save the scheme**
   - Click "Save As"
   - Name it `Cthulhu`
   - Click OK

### Method 2: One-Click Install

1. Right-click the `install.inf` file
2. Select **"Install"**
3. Go to Mouse Settings → Pointers → Scheme → Select `Cthulhu`

## 🚀 Usage

### Switching Schemes

Once installed, you can switch pointer schemes anytime:

1. Open **Mouse Settings → Pointers**
2. Choose `Cthulhu` from the "Scheme" dropdown
3. Click "OK"

### Restoring Defaults

To revert to the default Windows cursors:
- Select `Windows Default (system scheme)` from the "Scheme" dropdown
- Click "OK"

### Adjusting Pointer Size

If the pointers feel too small or too large:
- `Win + I` → Accessibility → Mouse pointer and touch
- Drag the slider to adjust size

## ❓ FAQ

<details>
<summary><strong>Q: The cursors didn't change after installation?</strong></summary>

1. Make sure the `Cthulhu` scheme is selected in Mouse Settings.
2. Try restarting Windows Explorer: `Ctrl + Shift + Esc` → find "Windows Explorer" → right-click → Restart.
3. Check whether the cursor files have been moved — if so, re-browse each pointer.
</details>

<details>
<summary><strong>Q: Animated cursors don't animate?</strong></summary>

- Ensure you are using the `.ani` files, not `.cur`.
- Some older systems may not fully support animated cursors. Windows 10+ is recommended.
</details>

<details>
<summary><strong>Q: How do I uninstall?</strong></summary>

1. Mouse Settings → Pointers → Scheme → Select a different scheme.
2. Delete the cursor folder.
</details>

<details>
<summary><strong>Q: Can I use these on macOS / Linux?</strong></summary>

This cursor set is in Windows-specific formats (`.cur` / `.ani`). macOS and Linux require conversion tools or platform-native cursor themes.
</details>
